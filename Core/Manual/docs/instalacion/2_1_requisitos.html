Requisitos

Servicio

Para el servidor

  • Un servidor http capaz de hospedar aplicaciones ASP.NET.
  • Una instancia de SQL Server capaz de utilizar tablas en memoria.

Para el cliente

  • Una versión de Windows 10 1607+ o Windows 11 22000+, 32/64 bits.

IDE

  • Una instancia de SQL Server 2019 o mayor.
  • .NET Desktop Runtime 8.0+

Canelary requiere un software de gestión de producción para validar las etiquetas con sus respectivos productos.
Canelary incluye una integración con Twins Informática - PiQuatro. Pero permite la integración con otros sistemas, siempre y cuando se desarrolle el modulo necesario para su compatibilidad.
