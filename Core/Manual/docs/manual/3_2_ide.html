Manual del IDE

Las funcionalidades del IDE están divididas en:

  • Módulos
  • Editor
  • Comparador
  • Verificador
    • Generar Muestra
    • Generar RE-CAL-22
  • Integración con git

Al abrir el programa se nos presenta con la pantalla inicial:

Pantalla inicial

La pantalla inicial esta dividida en dos partes:

Estado: Contiene una tabla con el estado de todos los puestos operativos, información brindada por el servicio (ver 3.1. Servicio). Y la ultima versión subida al repositorio (ver 3.2.5. Integración con git).

Canelary: Contiene una lista de funciones, cada función es un modulo instalado (ver 3.2.1. Módulos).
